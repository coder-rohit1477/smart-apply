# Smart Apply

An AI-powered job search platform that helps users:

- Upload and analyze resumes
- Match resumes with jobs using AI
- Track applications through a hiring pipeline
- Optimize ATS scores
- Get AI-powered resume feedback
- Manage the hiring process through a modern dashboard

## Tech Stack

- Next.js
- TypeScript
- Prisma
- SQLite / PostgreSQL
- Supabase
- Clerk Authentication
- Gemini AI
- Tailwind CSS

## Features

- Resume parsing (PDF/DOCX)
- AI-powered resume analysis
- ATS optimization
- Job matching engine
- Application tracking pipeline
- Resume rewriting
- Skill gap analysis
- AI feedback generation
